最初の3分

  1. index.html をChrome、Edge、Braveなどのブラウザで開きます。
  2. 画面上部の JSON取込 を押します。
  3. 同じフォルダにある links_51.json などを選びます。複数選択も可能です。
  4. 初回は 新規情報として取り込む のまま進みます。
  5. 取込予定を確認し、取込実行 を押します。
  6. 画面左側に追加されたリンク集のチェックボックスをオンにします。
  7. 検索欄へ 動画 などと入力し、検索 を押します。

重要: 登録内容はブラウザ内に保存されます。ブラウザのサイトデータを削除する前に、JSON出力でバックアップしてください。

画面の見方

画面上部検索、検索範囲、リセット、JSON取込を操作します。
左側登録済みのリンク集を切り替え、管理画面や操作ログを開きます。
中央表示中のリンクから作られたカテゴリで絞り込みます。
右側条件に一致したリンク、管理画面、操作ログを表示します。

検索と絞り込み

キーワードで検索する

検索欄へ名前、URL、カテゴリ、メモに含まれる言葉を入力し、検索 を押します。複数の言葉をスペースで区切るとAND検索になります。

例: 検索 ニュース

リンク集を切り替える

左側のチェックボックスで、現在の画面に表示するリンク集を切り替えます。AreaB未選択も検索を有効にすると、検索中だけ未選択のリンク集も検索対象にできます。

カテゴリで絞り込む

中央のカテゴリを選ぶと、該当するリンクだけを表示します。検索語とカテゴリは組み合わせて利用できます。

最初の状態へ戻す

リセットを押すとページを再読み込みします。登録データそのものは削除されません。

リンクの登録・編集

  1. 左側の 登録情報の更新 を押します。
  2. 新しいリンク集を作る場合は、管理画面右上の 新規作成 を押します。
  3. 既存のリンク集を変更する場合は、上部の一覧から対象を選びます。
  4. Title、サブタイトル、リンク名、URL、カテゴリ、メモなどを入力します。
  5. Web Storage更新 を押して保存します。

アイコンを設定する場合は、編集フォームのicon欄を選択してから、左側に表示されたアイコンをクリックします。

バックアップと移行

バックアップする

  1. 登録情報の更新を開きます。
  2. 保存したいリンク集の JSON出力 を押します。
  3. 出力されたJSONファイルを安全な場所に保管します。

別のPCやブラウザへ移す

  1. 移行元で必要なリンク集をJSON出力します。
  2. 移行先で index.html を開きます。
  3. JSON取込から、出力したJSONファイルを取り込みます。

JSON取込方法の違い

方法動作使う場面
新規情報として取り込む空きIDを自動で割り当てて追加初回利用、既存データを残して試す
上書き同じ内部IDのデータを置き換えるバックアップから元のリンク集を復元する
マージ既存データと取込データを結合する二つの環境のリンクをまとめる
取り込まないそのファイルを処理対象から外す選択を取り消す

よくある質問

起動してもリンクが表示されません

初回はリンク情報が登録されていません。JSON取込から同梱のサンプルJSONを取り込んでください。

JSONファイルを編集しても画面が変わりません

画面はWeb Storageに保存されたデータを表示します。編集したJSONファイルを、もう一度JSON取込してください。

データはどこに保存されますか

このアプリを開いたブラウザのWeb Storage（Local Storage）に保存されます。別のブラウザやPCには自動で共有されません。

ブラウザのブックマークを読み込めますか

現在、ブラウザ標準のブックマークファイルの自動取込には対応していません。リンクリスト形式のJSONを取り込むか、管理画面から登録してください。

ローカルファイルを開けません

ブラウザのセキュリティ設定により、ローカルパスへのリンクが制限される場合があります。登録したパスを確認し、必要な場合はファイルを直接開いてください。
